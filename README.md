The student-facing tryout page. **This repository is generated** — it is a copy of the
page and the modules it loads, published from a private repository so that GitHub Pages
can serve it. Editing anything here by hand will be overwritten.

It contains no answer keys, no access codes, and no roster. Every rule that decides a
score, a deadline, or who may take a test is enforced on the server, not in this code,
which is why publishing it changes nothing about who can see what.
